# Presentation Design Prompt Guide
*How to give Claude specific instructions so your slides don't look like a default template*

---

## Color & Mood
Instead of vague terms like "professional colors," be explicit:

- *"Use a dark navy (#0D1B2A) background with warm amber (#E8A838) accents — no white backgrounds"*
- *"Monochromatic palette — shades of forest green only"*
- *"High contrast black and white with a single pop color: coral"*
- *"Muted, earthy tones — terracotta, sand, and olive"*

---

## Typography
Specify fonts and personality:

- *"Use Playfair Display for headings, Inter for body text"*
- *"Bold, oversized headings that bleed to the edge — editorial magazine style"*
- *"No default sans-serif corporate fonts"*
- *"All caps headings, generous letter-spacing"*

---

## Layout Style
Describe the spatial feel:

- *"Asymmetric layouts — text left-heavy, visuals offset to the right"*
- *"Full-bleed image slides with text overlaid, not side-by-side"*
- *"Lots of white space — minimal text per slide, almost poster-like"*
- *"Dense data-journalism style, like a NYT infographic"*
- *"Grid-based, structured — every element aligned to a clear system"*

---

## Visual References
The most powerful lever — **name a reference**:

| Reference | Style it evokes |
|---|---|
| Stripe product deck | Clean, modern, developer-friendly |
| Apple keynote | Ultra-minimal, one idea per slide |
| McKinsey strategy deck | Structured, data-forward, corporate |
| Monocle magazine | Editorial, typographic, sophisticated |
| Vice Media | Bold, dark, provocative |
| Behance portfolio | Creative, visual-first, dynamic |
| TED talk slides | Simple, human, story-driven |

---

## Content Philosophy
Control how ideas are expressed:

- *"Max 8 words per slide — no bullet points anywhere"*
- *"Every slide needs a strong visual metaphor, no generic stock-photo energy"*
- *"Lead with a provocative statement, support with data below"*
- *"One idea per slide, always"*
- *"Use large numbers/stats as the hero element on data slides"*

---

## Slide Structure Options
Describe the overall deck architecture:

- *"Open with a full-bleed cover slide, close with a single bold call-to-action"*
- *"Section divider slides between each chapter — dark background, single word"*
- *"No more than 10 slides total — force prioritisation"*
- *"Each slide has a title, one visual, and a one-line takeaway at the bottom"*

---

## ⚡ Strong Prompt Template
Copy and adapt this for any presentation:

```
Create a [NUMBER]-slide [TYPE: pitch deck / keynote / report] with:
- Background: [COLOR/HEX]
- Text: [COLOR/HEX]  
- Accent color: [COLOR/HEX]
- Heading font: [FONT NAME] — [style description]
- Layout style: [asymmetric / centered / editorial / grid]
- Visual reference: inspired by [REFERENCE]
- Content rule: [no bullet points / max X words / one idea per slide]
- Mood: [adjectives — bold, minimal, warm, clinical, etc.]
```

### Example:
> *"Create a 10-slide pitch deck with a dark background (#111), white text, and one accent color (electric blue). Use Bebas Neue for all headings — large and full-width. Layouts should be asymmetric and editorial, inspired by a Vice Media documentary style. No bullet points. Each slide has one bold idea and a single supporting visual or stat."*

---

## Phrases to Avoid
These lead to generic output:

- "Make it look professional"
- "Use modern colors"
- "Clean and simple design"
- "Corporate style"

Replace them with **specific hex codes, font names, layout descriptions, and named references.**

---

*Tip: The more you sound like a creative director giving a brief, the better the result.*
